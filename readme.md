k6 version гаралт: `k6.exe v2.3.0 (commit/e088784614, go1.26.8, windows/amd64)`
<hr>

### Дүгнэлт
Энэ лабаар тестийн сценарио бичиж, түүнийг k6 тестийн програмаар биелүүлж хийж үзэв. SLO-сонгосон утгуудад: cart/add -н p95 < 5 (lокал сервер учир маш хурдан), /report p95 p95 < 400 (хамгийн муу үед 400), /pay error rate < 7% (сервер 5% алдаатай), 85%-ийн аvailability (error budget-с ойролцоогоор 2х дахин). Хамгийн чухал ажил нь тестийн сценариог анх бичэх байсан. Учир нь эхлээд системээ мэдэж бичих хэрэгти тул. Chaos туршилтад availability хэмжүүрийг хугацаа/хэмжээний ялгаатай байсан ч давав. Учир нь сценариод availability тоог их хэмжээтэй бичэн учир. Энд хугацаа/хэмжээний ялгаа нь 10с-н цонхонд их хэмжээний хүслэт ирж, тоо нь зөрөөтэй болдог.
